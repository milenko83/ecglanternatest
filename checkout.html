Check-Out Information

Please follow these steps before departure

📅 Before Departure
Send a WhatsApp message 1–2 days before departure.
Include your mobile home number and preferred check-out time.
Check-out time is between 7:00 AM – 10:00 AM.
A team member must inspect the house and collect the key.
🧹 Basic Cleaning Required
Empty all trash bins
Wash and sort dishes
Remove bed linen
Sweep the floor
Clean the grill if used
Note: To avoid issues with the deposit, please complete the required basic cleaning before departure.
🔑 If You Leave Early
Close all windows
Turn off the fridge and set it to “0”
Leave the key on the table inside the house
